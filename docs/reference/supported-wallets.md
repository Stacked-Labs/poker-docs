# Supported wallets

Stacked Poker works with popular wallets for signing in, adding funds and cashing out, so you're not locked into one wallet. If you don't have a wallet, Stacked can create one for you.

## Wallets you already have

You can sign in with a wallet you already control. Common options:

- **Coinbase Wallet.** Works well, especially if you're sourcing USDC from a Coinbase account. USDC is a digital dollar that holds a stable value.
- **MetaMask.** A popular wallet app. It switches to Base (an Ethereum-based network with very low fees) when prompted.
- **Rainbow.** Mobile-first.
- **WalletConnect-compatible wallets.** Rabby, Trust Wallet, Zerion, Frame, Ledger Live and many others.

If your wallet supports Base and signs Ethereum messages, it almost certainly works on Stacked.

## The wallet Stacked creates for you

If you don't have a wallet, Stacked creates one for you. Sign in with Google, Discord, Telegram, X, Apple, Twitch, email or your phone number, and Stacked sets up the wallet behind the scenes. Each sign-in method gets its own wallet, so use the same one every time.

The wallet is yours. You can export its keys later if you ever want to move to a different wallet app.

## What network and token

Real-money play runs on **Base**, and every real-money table uses **USDC** on Base. Make sure your wallet is set to Base when prompted. Most wallets switch automatically when Stacked asks.
